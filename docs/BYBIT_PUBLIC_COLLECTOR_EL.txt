Συλλογή δημόσιων μετρήσεων Bybit Global — χωρίς API key

1. Χρειάζεται Python3 εγκατεστημένη στα Windows. Δεν απαιτεί πρόσθετες βιβλιοθήκες.
2. Αποσυμπίεσε όλο το πακέτο. Άνοιξε START_BYBIT.cmd.
3. Περίμενε μέχρι να ολοκληρωθεί ή να αναφέρει σφάλμα. Αν όλα λειτουργήσουν, διαρκεί περίπου2–3λεπτά.
4. Ανέβασε εδώ το bybit_measurements_....zip που δημιουργείται στον ίδιο φάκελο.

Διαβάζει μόνο δημόσια GET endpoints api.bybit.com: instruments, funding, ticker, orderbook. Δεν ζητά κλειδιά, δεν ανοίγει λογαριασμό και δεν στέλνει εντολές. Δεν χρησιμοποιεί εναλλακτικούς hosts ή αυτόματες επαναλήψεις μετά από σφάλμα.

Δοκιμάστηκε σε Python3.12/Linux, με συνθετικά δεδομένα και έλεγχο χωρίς site-packages. Η πραγματική πρόσβαση από τον δικό σου υπολογιστή και το Windows launcher δεν έχουν εκτελεστεί εδώ. Αν αποτύχει, στείλε το παραγόμενο ZIP με το σφάλμα.

Οι αριθμοί βάθους θα είναι πραγματικά στιγμιότυπα μόνο όταν η δημόσια API επιστρέψει έγκυρα πρόσφατα δεδομένα. Οι υποθετικές εκτελέσεις, η προμήθεια και το σταθερό ποσό funding δεν είναι πραγματικό account PnL.
